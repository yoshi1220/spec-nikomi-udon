# Start a change from an existing file

Read the specified file before creating the branch. Identify how unreadable or contradictory passages affect the draft. If you cannot read the primary input, explain why and ask for a readable version or the relevant excerpt.

Follow [Prepare a specification](../nikomu/references/prepare-spec.md) from `nikomu`. Draft `nikomi.md` using information you can establish from the file and cite the source. Then read and follow the same required [clarification workflow](../nikomu/references/clarify-spec.md) and its references through the user's final review.
