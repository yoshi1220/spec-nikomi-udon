# Start a change from an existing file

Read the specified file before creating the branch. Mark unreadable or contradictory passages as Unconfirmed, identify their locations and effect on the draft, and state what evidence would resolve them. When the user needs to choose a requirement, label it User decision required following the shared preparation procedure. If you cannot read the primary input, explain why and ask for a readable version or the relevant excerpt.

Follow [Prepare a specification](../nikomu/references/prepare-spec.md) from `nikomu`. Draft `nikomi.md` using information you can establish from the file and cite the source. Then read and follow the same required [clarification workflow](../nikomu/references/clarify-spec.md) and its references through the user's final review.
