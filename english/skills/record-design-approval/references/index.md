# Prepare the deliverable index and migrate an existing PBI

Run the installed [approval.py](../scripts/approval.py) in the target repository. The syntax below is `python3 <approval.py> [--change specs/<change>] ACTION`.

- For a new PBI, run `init` after the first save of `shikomi.md`. It creates a missing index from the deliverable template and adds the approval section only for `operational` or `pr`. Preserve that section when updating other deliverables.
- `sync-spec` reads the review marker on the first line of `shikomi.md` and updates the change specification row. It marks the row “Complete” for `confirmed` and “In progress” otherwise. It creates a missing index from the template. If a custom format prevents the helper from identifying the row, update the specification status cell to match the review marker in `shikomi.md`.
- When starting design, approval or planning, read `status`. The states are `off`, `pending`, `approved` and `emergency`. If reading fails, resolve the reported issue and retry. If a workflow lock remains after an interruption, check the PID in the reported file and verify with other users of the worktree that the operation has ended. Inspect the affected files, move the stale lock aside, then retry.
- `uninitialized` means approval is enabled but the index has no approval section. Inspect this PBI's existing index, old `dandori.md` and any supporting records. For an authorized emergency exception with its recorded reason, import it with `emergency --reason "original reason"`. If the evidence identifies approval of this design, its date and approver, import it with `migrate --date YYYY-MM-DD --approver "reviewer"`. An old plan or a decision to proceed after a failed PR lookup alone does not establish approval. If evidence is incomplete, run `init` to mark the design pending and put any existing plan on hold. The plan keeps its tasks and results. Continue drafting when called from `draft-basic-design`. For normal planning, obtain and record approval of the completed draft with `record-design-approval` first.
