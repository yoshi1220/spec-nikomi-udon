# Start a change from an existing file

Read the specified file before creating the branch. Mark unreadable or contradictory passages as Unconfirmed (user confirmation required). Identify their locations, their effect on the draft, and what evidence or choice you need from the user, following the shared preparation procedure. If you cannot read the primary input, explain why and ask for a readable version or the relevant excerpt.

Follow [Prepare a specification](../specify-spec/references/prepare-spec.md) from `specify-spec`. Draft `shikomi.md` using information you can establish from the file and cite the source. Then read and follow the same required [clarification workflow](../specify-spec/references/clarify-spec.md) and its references through the user's final review.
