# 実装した変更を E2E テストで確かめる

対象ディレクトリは利用者の指定を使う。指定がなければ、現在の `feature/<変更名>` ブランチに対応する `specs/<変更名>/` を使う。対象を特定できない場合や、別の変更のブランチにいる場合は、作業先を利用者に確認する。

- `evidence/<実行ID>/recovery.md` に進行中または利用者の対応待ちの復旧があれば、[復旧手順](references/recover.md) で記録済みの段階から続ける。
- 通常の実行では、[E2E テスト手順](references/run-e2e.md) に従い、現行の仕様・計画とテスト項目を照合する。プロジェクト設定の方法でテストして結果を記録し、現在の実行 ID にひもづく結果から、不合格の復旧または担当者の確認に進む。
- `verify-e2e` で現行の変更に対する合格と担当者の確認が有効と判定されたら、`osameru` に進めることを伝える。
