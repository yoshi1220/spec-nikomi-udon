# 課題と取り組む方向を決める

1. 相談内容、指定資料、既存システムの関連箇所を読む。再開時は指定されたまとめを優先し、指定がなければ今回の相談に対応する `saguri/<相談名>/saguri.md`、案件内の `saguri.md`、または前回の会話を読み、合意と保留理由を引き継ぐ。[論点の組み立て方](references/map-problem.md) に沿って、目的ごとに分かっていることと、方針を選ぶ前に確かめることを整理する。
2. 前提がそろった論点のうち、答えが対象範囲や方針を最も大きく変えるものを一つ尋ね、返答を待つ。事実が足りなければ、具体的な場面や資料を自由に答えられる質問にする。方針を選ぶ質問では、実行できる案を原則３つ、推奨順に番号付きで示す。最初の案を推す理由、他案を選ぶと変わる点を短く添える。案が少なければその数でよい。別案や条件付きの回答も自由入力で受け付ける。
3. 回答のたびに、分かったことと根拠を会話内のまとめに反映する。[回答の再点検と終了条件](references/review-discovery.md) に従い、前提が変わった判断を開き直す。質問候補を使い切ったら元の相談から点検し直し、新たな不足や矛盾が見つかれば次の一問へ戻る。質問数やラウンド数に上限を設けない。
4. 再点検の結果を示し、利用者の判断に沿ってまとめる。「進む・追加で調べる・見送る」の判断がまだなら、現時点で選べる案を示して返答を待つ。
5. 終了時は[まとめの保存と引き継ぎ](references/keep-summary.md) に沿って、保存先または「この会話だけ」を一問で確認する。すでに指定された選択はそのまま使う。
