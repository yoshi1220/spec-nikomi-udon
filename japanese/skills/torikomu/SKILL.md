# 既存ファイルから変更仕様を起こす

指定されたファイルを実際に読んでから作業ブランチを作る。読み取れない箇所や互いに矛盾する記述があれば、初稿にどう影響するかを区別する。主入力を読み取れないときは、理由を伝え、読める形式や必要な抜粋を尋ねる。

セットで配布される [nikomu の準備手順](../nikomu/references/prepare-spec.md) に従う。ファイルから確認できる内容だけで `nikomi.md` の初稿を作り、参照元を記す。その初稿を使い、[明確化の共通手順](../nikomu/references/clarify-spec.md) とその参照ファイルを必ず読んで、利用者の最終確認まで同じ手順で進める。
